# blog-assets

Public CDN asset repository for [blogs.redwan.work](https://blogs.redwan.work).

Contains optimized post hero images, artwork, and thumbnails automatically served globally via jsDelivr CDN:

```
https://cdn.jsdelivr.net/gh/redwan-cse/blog-assets@main/posts/<slug>/thumbnail.png
```

---

## 🔒 Security & Access

- This repository is **publicly readable** to enable fast global CDN distribution.
- **Write and push access is strictly restricted** to the repository owner and authorized automated publishing workflows. External contributions or push attempts are blocked.
